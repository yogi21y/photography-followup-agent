# סוכן מעקב פניות לעסק צילום

סוכן בינה מלאכותית (AI agent) שעובר כל בוקר על פניות הלקוחות של עסק צילום, מוצא פניות שהגיע הזמן לחזור אליהן, ומנסח טיוטות להודעות המשך. ההחלטה אם לשלוח נשארת אצל בעל העסק.

הפרויקט נבנה כמטלה לשיעור 6 בקורס מטמיעי AI (סוכני AI), נובמבר 2026.

## הקבצים בריפו

1. `SPEC.md`: תכנון מפורט של הסוכן. איך הוא פועל, באילו כלים הוא משתמש ואיך מנהלים את הזיכרון שלו.
2. `Architecture.md`: תרשים זרימה של כל המערכת, מאיפה מגיע המידע ולאן הוא נשלח.

## פרויקטים קשורים

1. דאשבורד הפניות שקורא מאותה טבלה: `yogi21y/photography-leads-dashboard`
2. תרחיש Make שמכניס פניות חדשות לטבלה: `yogi21y/make-leads-automation`

## אבטחה
